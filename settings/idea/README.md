# IntelliJ IDEA Settings

These files provide IntelliJ IDEA configurations based on the workspace's VS Code settings:

- **Theme & Colors** (`colors.scheme.xml`): Sets up the Catppuccin Mocha color theme for editor windows and consoles.
- **File Types** (`filetypes.xml`): Excludes build output directories (`target`, `node_modules`) from search/indexing.
- **Code Styles** (`codeStyles/Project.xml`): Configures formatters for JSON (2-space indent) and Markdown files.
