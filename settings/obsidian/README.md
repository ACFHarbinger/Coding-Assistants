# Obsidian Settings

These files provide Obsidian settings designed to align with the visual and structural preferences configured in the workspace's VS Code settings:

- **Appearance** (`appearance.json`): Sets the theme to Catppuccin Mocha, specifies custom accent colors (`#6366f1` matching VS Code primary selections), and enables translucency.
- **App Configuration** (`app.json`): Defines editor behaviors, tab sizes, line numbers, and spellchecking settings.
- **Core Plugins** (`core-plugins.json`): Pre-activates standard note-taking plugins such as the file explorer, global search, and outline panels.
