# Sublime Text Settings

These files provide Sublime Text configurations mirroring the project's VS Code environment:

- **Preferences** (`Preferences.sublime-settings`):
  - Configures the **Catppuccin Mocha** color scheme.
  - Sets JetBrains Mono as the active editor font.
  - Automates whitespace trimming, tab translations (spaces over tabs), and final newline insertion upon saves.
  - Sets project exclusions to ignore compilation directories (like `.venv`, `node_modules`, `.gradle`, `dist`, `target`) in folder search trees.
