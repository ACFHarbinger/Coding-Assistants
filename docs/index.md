# Coding-Assistants Documentation

Welcome to the documentation portal for **Coding-Assistants**, a Tauri 2 +
React 19 desktop app that orchestrates multiple LLM coding-agent CLIs
(Claude, Gemini, ChatGPT, and more) with a Rust backend and an optional
Kotlin/Android companion app for remote control over TCP.

## Where to Start

- [Architecture](ARCHITECTURE.md) — System design and module boundaries (frontend, backend, Android companion)
- [Development](DEVELOPMENT.md) — Local setup, build prerequisites, and workflow
- [Testing](TESTING.md) — How to run unit, integration, and benchmark tests
